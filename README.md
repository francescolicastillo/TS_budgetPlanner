# Budget Planner in TypeScript

App to track your budget. Add incomes and expenses, see your remaining balance. Data is saved in localStorage (budgets, transactions) so everything stays after refresh.

Clean, minimal UI with inline editing. Built with TypeScript for type-safe logic and easy maintenance.

## Demo

ts-budget-planner.vercel.app

## Tech-stack

- HTML
- CSS
- TypeScript
- node
- localStorage

## Project Setup

```sh
npm install
```

### Compile

```sh
npm run build
```
